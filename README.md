# Fonitas Developers

Independent Next.js developer website at **developers.fonitas.com**, repository **gemvc/fonitas-developer-website**. Fonitas publishes applications; developers register as individuals, companies or development teams.

The portal implements account registration/login/MFA/verification/reset, a developer dashboard and resumable private developer registration. Application registration and later workflow screens remain the next implementation stages. No sample applications, fake counts or active placeholder controls represent those stages.
