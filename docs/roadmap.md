# Developer website roadmap

Only unfinished Developer Hub work belongs here. Authenticated application management belongs to the separate Developer Dashboard and is not a roadmap for this repository.

| ID | Stage | Acceptance |
| --- | --- | --- |
| WEB-001 | Public information architecture | Home, Guide, Publishing rules and FAQ remain the public documentation surface. Blog is reserved for a later page-by-page implementation step. |
| WEB-002 | Content completeness | Official Fonitas workflow and publishing rules are reviewed and expanded without inventing backend behavior. |
| WEB-003 | Developer Dashboard handoff | A configured, clearly labeled CTA routes users to the separate Developer Dashboard without recreating authenticated workflows in this site. |
| WEB-004 | Content navigation and search | Documentation navigation and, if content volume requires it, search make public rules and guides easy to discover. |
| WEB-005 | Localization parity | New public content remains complete and accurate in English, Persian and Arabic, including RTL presentation. |
| WEB-006 | Visual and responsive polish | Fonitas branding, typography, spacing, accessibility and mobile layouts are validated across supported viewport sizes. |
| SEC-001 | Dependency audit follow-up | Recheck the inherited development dependency advisory when a compatible upstream fix is available; do not disable lint or force an unsupported framework downgrade. |

The backend contract remains the authority for application, review, QA, publishing and Gallery behavior. This website documents that lifecycle; it does not implement it.
